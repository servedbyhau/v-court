# V Court

V Court is a new Android project for unattended tennis court booking on a phone. Its intended daily run does not depend on a Windows PC, an emulator, or a desktop service.

This repository is being planned. It contains no booking implementation yet. The earlier `vh-tennis-booker` project is a reference for observed app behavior and proven booking checks; its source has not been imported here.

## Current scope

- Run the booking flow on an Android phone at the configured opening time.
- Confirm the result from the app's own booking ticket before reporting success.
- Keep the user informed of failures and uncertain outcomes.
- Verify operation with the phone locked and after ordinary device interruptions.

See [the project plan](docs/PLAN.md) for milestones and decisions to settle before implementation.

V Court is a personal project and is not affiliated with or endorsed by Vinhomes.
